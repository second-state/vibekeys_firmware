Atlas 换皮验证

两列跑的是同一份合成代码(相同 DOM、相同坐标、相同 blit 槽位)。 左 = 品牌绿 atlas + 绿调色板;右 = 原神 atlas + 原神调色板。 差异只有 一个文件:atlas.png —— 底部 4px 色板条(16 槽)即调色板,固件从固定偏移读入,文字色/焦点底色/框线色全部数据驱动,不再需要每主题一份常量表。
注意 选中条:合成代码里两列都是同一个 blit 槽位,绿皮肤烘焙的是纯色条,原神皮肤烘焙的是「金边 + 角标 + 预混金底」—— 非矩形的选中框就是这样做进皮肤的。
